# 📈 Stock Market Trend Analysis Using Python

## 📌 Project Overview

This project analyzes stock market trends using Python and data visualization techniques. It uses historical stock price data to visualize changes in closing prices over time through a line graph.

The project helps understand stock price fluctuations and identify overall market trends using Python libraries.

## 🎯 Objectives

- Analyze stock market closing prices over time.
- Visualize stock price fluctuations.
- Understand trends using line charts.
- Practice data analysis and visualization using Python.

## 🛠️ Technologies Used

- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Google Colab** – Development environment

## 📂 Project Structure

```text
Stock-Market-Trend-Analysis/
│
├── Stock_market.ipynb
├── stock_data.csv
├── line_plot.png
└── README.md
```

## 📊 Dataset Information

The project uses a CSV file named `stock_data.csv`.

The dataset contains the following columns:

| Column | Description |
|---|---|
| Date | Stock observation date |
| Closing Price | Stock closing price |

## ⚙️ Installation and Execution

**Step 1:** Clone the repository.

```bash
git clone https://github.com/karanbagade236-sketch/Stock-Market-Trend-Analysis.git
```

**Step 2:** Navigate to the project folder.

```bash
cd Stock-Market-Trend-Analysis
```

**Step 3:** Install the required libraries.

```bash
pip install pandas matplotlib
```

**Step 4:** Open the Jupyter Notebook or upload it to Google Colab.

**Step 5:** Upload `stock_data.csv` and run the notebook cells.

## 📈 Project Output

The project generates a line graph titled:

**Closing Price Trend over Time**

The graph represents stock closing prices against dates and highlights fluctuations and the overall price trend.
